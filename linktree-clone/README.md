# Linktree Clone

Pagina personale di collegamenti ispirata a Linktree.

Parte di [**EPICODE Bootcamp**](../README.md), nella cartella `linktree-clone/`.

## Tecnologie

HTML, CSS, JavaScript.

## Struttura e utilizzo

Apri [`index.html`](index.html) nel browser oppure servi questa cartella con un server statico locale. Stili e comportamento sono in [`style.css`](style.css) e [`main.js`](main.js).
