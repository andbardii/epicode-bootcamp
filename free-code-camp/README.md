# freeCodeCamp

Esercizi personali di Responsive Web Design svolti su freeCodeCamp, raccolti insieme ai materiali del bootcamp.

Parte di [**EPICODE Bootcamp**](../README.md), nella cartella `free-code-camp/`.

## Tecnologie

HTML, CSS.

## Struttura e utilizzo

Gli esercizi sono in [`ResponsiveWebDesign/`](ResponsiveWebDesign/). Apri i file HTML nel browser oppure usa un server statico locale; non è previsto un processo di build unico.
