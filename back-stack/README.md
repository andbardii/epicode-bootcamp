# Back Stack

Lezioni ed esercizi del percorso backend EPICODE, dalle basi di Java alle applicazioni Spring.

Parte di [**EPICODE Bootcamp**](../README.md), nella cartella `back-stack/`.

## Tecnologie

Java, Spring Boot, PostgreSQL, Hibernate.

## Struttura e utilizzo

Le cartelle `Lezione_*` raccolgono le lezioni; le altre contengono progetti e prove. Apri ciascun progetto separatamente. Per i progetti Maven esegui i comandi dalla cartella con `pom.xml`; configura il database locale quando previsto.
