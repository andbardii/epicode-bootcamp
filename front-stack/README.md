# Front Stack

Esercizi e progetti del percorso frontend EPICODE: HTML, CSS, JavaScript, TypeScript e Angular.

Parte di [**EPICODE Bootcamp**](../README.md), nella cartella `front-stack/`.

## Tecnologie

HTML, CSS, Sass, JavaScript, TypeScript, Angular.

## Struttura e utilizzo

I materiali sono organizzati in `pre/`, `m1/`, `m2/` e `m3/`. Apri il singolo esercizio; per le app Angular entra nella cartella che contiene `package.json` e consulta il relativo README. Non esiste un comando di avvio unico per tutta la raccolta.

## Cronologia e licenza

Progetto originariamente ospitato in `andbardii/front-stack`, ora integrato in questa raccolta. La repository separata è stata eliminata dopo la migrazione. La cronologia originale è conservata nella raccolta; il tag `migration/front-stack` identifica l’ultimo commit importato.

Vedi la [cronologia della raccolta](../README.md#provenienza-e-cronologia) e la [licenza del progetto](LICENSE).
