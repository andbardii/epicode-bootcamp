# Weather Angular App

Applicazione Angular per consultare il meteo tramite API esterne.

Parte di [**EPICODE Bootcamp**](../README.md), nella cartella `weather-angular-app/`.

## Tecnologie

Angular 16, TypeScript, Sass, Bootstrap.

## Struttura e utilizzo

Il frontend è in [`weather/`](weather/). Dalla radice della raccolta:

```sh
cd weather-angular-app/weather
npm ci
npm start
```

Configura le credenziali richieste dal servizio meteo prima di usare le chiamate API. Vedi anche il [README Angular](weather/README.md).
